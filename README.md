# MV Lib Testing Ground

A demonstration and validation application designed to support the development of **MV Lib**.

[View the application](https://gtouchet.github.io/mv-lib-testing-ground/home)

## Purpose

This project serves as a **sandbox** for testing, visualizing, and validating components from the MV Lib library in conditions that closely resemble real-world usage.

It allows you to:

- Verify the visual and functional behavior of MV Lib components.
- Test different configurations and variants.
- Quickly reproduce specific use cases.
- Detect regressions as the library evolves.
- Provide a showcase for the available components.

## Why this application?

When developing a component library, it is often useful to have a dedicated application that allows you to:

- Test components independently from any business application.
- Experiment with new features quickly.
- Simplify debugging and visual review processes.

This application addresses those needs by centralizing all examples and testing scenarios in a single place.

## How it works

Each view of the application highlights a component from the library in order to:

- Showcase its different properties.
- Test user interactions.
- Simplify configuration.
- Allow developers to quickly copy and paste the component's HTML code along with its current configuration.

The application evolves alongside the library and serves as a practical reference throughout its development.

## Intended Audience

This project is primarily intended for:

- The developer of the MV Lib library.
- Anyone interested in discovering or evaluating the available components.
- Demonstrating my Angular development skills.

## Status

This project is a testing and demonstration environment.

I frequently perform refactoring work that may temporarily break some components. When this happens, visitors are informed through notifications displayed on the application's home page.
