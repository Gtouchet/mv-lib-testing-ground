Button styles Use the MVLib button's [inputStyle] to customize its colors, dimensions, outline, and typography. Last updated: {{ lastUpdated }}
Style configuration
The button comes with a default style: every property of [inputStyle] is optional, so you only need to set the ones you want to override.
Tweak each style group in the Configuration tab.
Every style group is defined per button state (idle, hovered, selected, hovered and selected): pick the state to edit from the dropdown next to the group's title.
Click the button in the preview to toggle its selected state.
