Button hyperlink The [href] input turns the MVLib button into a native hyperlink and defines its navigation target. Last updated: {{ lastUpdated }}
HREF input When href contains a non-empty value, the component renders as an <a> element and supports native browser link behavior.
When href is undefined or an empty string, the component renders as a regular button.
A disabled component also renders as a button and does not navigate, even if href is set.
