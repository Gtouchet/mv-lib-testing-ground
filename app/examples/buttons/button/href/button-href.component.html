Button hyperlink Use the MVLib button's href in [inputSettings] to define the navigation settings.
The href settings turns the MVLib button into a native hyperlink and defines its navigation target. Last updated: {{ lastUpdated }}
HREF input When href contains a non-empty value, the component renders as an <a> element and supports native browser link behavior.
When href is undefined or an empty string, the component renders as a regular button.
When openInNewTab is true, the link opens in a new tab; otherwise, it opens in the current tab when left clicked.
A disabled component also renders as a regular button and does not navigate, even if href is set.
