Numeric textbox events The MVLib numeric textbox emits events for selection, value changes, and stepper button interactions. Last updated: {{ lastUpdated }}
Selection changes
The (onSelect) event is emitted when the input area gains or loses focus.
Its readonly payload contains the current selection state and the originating event.
Click inside and outside the textbox in the preview to see the emitted events in the log.
Usage 
<mv-lib-numeric-textbox
    (onSelect)="doSomething($event)"
/>

Value changes
The (onChange) event is emitted whenever the numeric value changes.
Its readonly payload contains the new value and the originating event.
Type a value or use the stepper buttons in the preview to see the emitted events in the log.

/>

Stepper button clicks
The (onStepperButtonClick) event is emitted whenever an increment or decrement button is clicked.
Its readonly payload contains the step direction and the originating event.
Click the stepper buttons in the preview to see the emitted events in the log.
Usage 
<mv-lib-numeric-textbox
    (onStepperButtonClick)="doSomething($event)"
/>

MvLibNumericTextboxStepperButtonClickedEvent:
{
    direction: 'increment' | 'decrement';
    event: Event;
}

Stepper button holds
The (onHoldStart) event is emitted when a stepper button hold begins.
The (onHoldEnd) event is emitted when the hold ends.
Both readonly payloads contain the step direction and the originating event.
Hold a stepper button in the preview to see the emitted events in the log.
Usage 
<mv-lib-numeric-textbox
    (onHoldStart)="doSomething($event)"
    (onHoldEnd)="doSomethingElse($event)"
/>
