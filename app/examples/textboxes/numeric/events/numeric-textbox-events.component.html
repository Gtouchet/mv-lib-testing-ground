Numeric textbox events Explore the events emitted when interacting with a numeric textbox and its stepper buttons. Last updated: 12/09/2026
Selection event The (onSelect) event is emitted whenever the textbox is selected or loses focus.
The event object contains readonly information about the selection state and the originating event.

    (onSelect)="doSomething($event)"
/>

Hold events The (onHoldStart) event is emitted whenever the hold action starts.
The (onHoldEnd) event is emitted whenever the hold action ends.
The event objects contains readonly information about the direction of the hold and the originating event. 
<mv-lib-numeric-textbox
    (onHoldStart)="doSomething($event)"
    (onHoldEnd)="doSomething($event)"
/>

MvLibNumericTextboxHoldStartedEvent:
{
    direction: 'increment' | 'decrement';
    event: Event;
}

{
    direction: 'increment' | 'decrement';
    event: Event;
