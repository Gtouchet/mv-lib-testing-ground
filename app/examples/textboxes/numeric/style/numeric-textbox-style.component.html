Numeric textbox styles Use the MVLib numeric textbox's [inputStyle] to customize its input area and stepper buttons. Last updated: {{ lastUpdated }}
Input area
The numeric textbox comes with a default style: every property of [inputStyle] is optional, so you only need to set the ones you want to override.
Configure the background color, dimensions, outline, and typography of the input area in the Configuration tab.
Color
Stepper button
Set the shared width of both stepper buttons in stepperButtons.width, and customize their background colors and icons independently in stepperButtons.increment and stepperButtons.decrement.
